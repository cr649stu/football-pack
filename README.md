# 传奇抽卡 · Football Pack

一个足球球员抽卡小游戏，单文件、零依赖：打开 `index.html` 就能玩。

## 内容

- 301 名球员、367 张卡：传奇 / 史诗（退役）、精选 / 普通（现役）
- 每日赠送 12 张抽卡券；每日 10 道足球题，答对一题再得 2 张
- 抽到重复卡返还 1 张券
- 卡面全部由内嵌 SVG 绘制（球衣按国家队配色、号码按名字生成），不依赖任何图片
- 支持 4 种阵型（4-3-3 / 4-4-2 / 3-5-2 / 4-2-3-1），点位置格子选人，阵容存在本地

## 运行

双击 `index.html`，或放进任意静态服务器。

## 数据

抽卡券、卡牌与阵容都存在浏览器 `localStorage`（键名 `football-pack.v2`），清掉站点数据会重置进度。
